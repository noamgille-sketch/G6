Comment le lancer

Il te faut Python 3.10 ou plus. Tout s'exécute sur ta machine.

  1. Récupère le dossier G6 Guard (la personne qui t'a envoyé ce lien l'a).
  2. Ouvre un terminal dans ce dossier et installe les dépendances : 
    pip install -r requirements.txt
  3. Lance la vérification : 
    python verify_client.py {{ link }}

Le scan écrit le rapport complet dans un fichier sur ton propre disque et affiche chaque résultat avant d'envoyer quoi que ce soit. Rien n'est transmis tant que tu n'as pas tapé oui. Tu veux le voir sans rien envoyer ? Ajoute --dry-run.

Lance-le en tant qu'administrateur pour la vérification la plus complète (mémoire et pilotes). Ça marche aussi sans, certaines vérifications seront simplement ignorées.
