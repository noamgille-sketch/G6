How to run it

You need Python 3.10+ installed. Everything runs on your machine.

  1. Download the G6 Guard folder (the person who sent you this link has it).
  2. Open a terminal in that folder and install the dependencies: 
    pip install -r requirements.txt
  3. Run the verification: 
    python verify_client.py {{ link }}

The scan writes the full report to a file on your own disk and prints every finding before uploading. It only sends it after you type yes. Want to see it first without sending anything? Add --dry-run.

Run it as Administrator if you want the deepest check (memory and drivers). It works without admin too, some checks will just be skipped.
